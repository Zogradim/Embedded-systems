This is a simple data array analysis project. The goals are to create a program to find the mean, the median, the maximum, and the minimum value of the array as well as sort the array from largest to smallest. The values will be printed on terminal along with the initial array as well as the sorted array. The repository includes three commits in the first are the three files given to me by the course's github the second gives a project outline and the third is the actual development of the project.
